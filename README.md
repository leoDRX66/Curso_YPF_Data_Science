## 📝 Descripción

Este repositorio contiene los notebooks, ejercicios prácticos y conjuntos de datos (*datasets*) en los que voy trabajando a lo largo del curso. El objetivo de este espacio es **documentar el progreso**, aplicar técnicas de análisis de datos y mantener un registro estructurado de las entregas requeridas por la cátedra.

## 📂 Estructura del Repositorio

```
Curso_YPF_Data_Science/
├── 📓 Notebook N-actualizado.ipynb   # Ejercicios resueltos por notebook
├── 📁 Docs/                      # Documentos de teoria
├── 📁 DataSets/                      # Fuentes de datos utilizadas
├── 📄 requirements.txt               # Dependencias del entorno
└── 📄 README.md
```

| Elemento | Descripción |
| :--- | :--- |
| **Notebooks (`.ipynb`)** | Resolución paso a paso de los ejercicios asignados, limpieza de datos y visualizaciones. |
| **`DataSets/`** | Directorio con las fuentes de datos utilizadas para los análisis. |
| **`requirements.txt`** | Dependencias exactas necesarias para reproducir el entorno virtual localmente. |

## 🚀 Cómo usar este repositorio

```bash
# 1. Cloná el repositorio
git clone https://github.com/leoDRX66/Curso_YPF_Data_Science.git
cd Curso_YPF_Data_Science

# 2. Creá un entorno virtual (opcional pero recomendado)
python -m venv venv
source venv/bin/activate      # En Windows: venv\Scripts\activate

# 3. Instalá las dependencias
pip install -r requirements.txt

# 4. Abrí Jupyter Notebook
jupyter notebook
```
