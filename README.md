# Curso Data Science YPF - Entregables

## Descripción
Este repositorio contiene los notebooks, ejercicios prácticos y conjuntos de datos (datasets) en los que ire trabajando. El objetivo de este espacio es documentar el progreso, aplicar técnicas de análisis de datos y mantener un registro estructurado de las entregas requeridas por la cátedra.

## Estructura del Repositorio
* **Notebooks (`.ipynb`):** Archivos con la resolución paso a paso de los ejercicios asignados, limpieza de datos y visualizaciones.
* **DataSets/:** Directorio con las fuentes de datos utilizadas para los análisis.
* **requirements.txt:** Archivo de configuración con las dependencias exactas necesarias para reproducir el entorno virtual localmente.

## Tecnologías Utilizadas
* Python
* Pandas
* Matplotlib & Seaborn
* Jupyter Notebooks
